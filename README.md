## 📂 Understanding the interface

The Codor dashboard displays all active agents in a list. Each entry shows the connection status, the agent name, and the current signal strength. 

- The green status light indicates a healthy connection.
- The yellow light suggests a delay in transmission.
- The red light means the agent is offline.

You click on an agent to open the detailed control panel. From here, you send custom commands or adjust individual settings for that specific tool. The main console shows a stream of all communications flowing through the channel. You use the filter bar at the top to search for specific messages or to hide inactive agents.
